# v0.1.73

Delivered 2026-11-19. Authoritative text: rows R-558 to R-561 of [ROADMAP](../ROADMAP.md).

- **R-558**: A2A streaming no longer prefixes the remote answer with "Task status: submitted/working". Fix `fae447e3b`:
  `ConversionResult.status_only` marks the fallback text, and `stream_message` skips it. Input required, auth required,
  canceled and errors keep their text; the non-streaming path is unchanged.
- **R-559**: the orchestrator system message generated by the operator (`delegation.go`, `orchestratorConfig`, commit
  `2fc513b07`) says to mark the work item done first, that an offer of more detail is not a reason to ask again, and keeps
  one exception. The bundle prompt of a task never reaches the orchestrator. The stored agent configs change, so the
  orchestrator agents are recreated when the operator rises.
- **R-560**: spans `execute_tool iem.delegate_task` carry `mas.delegation.work_item_id` and `mas.delegation.target`
  (allow-list in `otel_tracing_service.py`), so re-delegations can be counted per work item from Tempo.
- **R-561**: the first cut failed and was re-cut, see [R-561](incident-r561-image-index.md).
- Rollback is forward only (revert, then 0.1.74): OLM does not downgrade.
